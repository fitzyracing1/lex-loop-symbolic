# Lex loop: symbolic step

> **Status:** Spec: the rule and one worked example. No code.

A rule for fitzyracing1/lex-loop: before any physical action (trajectory, motion, control), find the governing differential equation and solve it symbolically. Worked example in chat: dy/dx = 2x(y-1) gives y = 1 + A e^(x^2).

## Where this came from

This idea came up in a chat with one of Joshua Almeida's bots (Lex bot, Oct 20 2026) and was not taken further at the time. This repo records it so it can be picked up later.
